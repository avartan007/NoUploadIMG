# Showcase notice

This repository is a **documentation and portfolio showcase** for NoUpload IMG.

## What is public here

- Product documentation written for recruiters and hiring teams
- Screenshots and animated tours of the interface
- The 48-second launch film in MP4 and GIF form
- The logo and visual assets

## What is not public here

- Application source code
- Build configuration or dependency manifests
- Internal file structure, tooling scripts or development notes
- Any file that could be used to reproduce the implementation

The original source is held in a separate **private** repository and is available on
request to recruiters and hiring teams.

## Why it is split this way

The product is the work of one developer. Keeping the implementation private protects
that work while still making the outcome, the design quality and the product thinking
easy to review.
